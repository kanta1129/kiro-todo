# タスク鮮度管理TODOアプリ 🍎🥬⏰

タスクを生鮮食品や燃料のように扱い、時間経過や重要度に応じてタスクの「鮮度」や「状態」を視覚的に表現するタスク管理アプリケーションです。

## 概要

このアプリは、タスクの期限が近づくにつれて視覚的に「劣化」していく独特なUIを提供します。新鮮なタスクは鮮やかな色で表示され、期限が近づくと徐々に色あせ、腐敗したような見た目に変化します。期限切れのタスクは「墓石」モードになり、内容が隠されます。

### 主な機能

- **鮮度状態の自動更新**: タスクの期限までの残り時間に応じて、視覚的な状態が自動的に変化
  - 🟢 **新規** (3日以上): 鮮やかで活き活きとした表示
  - 🟡 **期限接近** (1-3日): 彩度が下がり、わずかに褐色化
  - 🟠 **期限間近** (0-1日): 劣化エフェクト、カビの表現、暗色化
  - ⚫ **期限切れ**: 墓石モード（内容を隠す）

- **優先度ベースの劣化速度**: タスクの優先度に応じて鮮度の変化速度が調整される
- **墓石モード**: 期限切れタスクをクリックすると内容を表示可能
- **完了アニメーション**: タスク完了時の満足感のあるビジュアルフィードバック
- **リアルタイム更新**: ページをリフレッシュせずに鮮度状態が自動更新
- **ローカルストレージ永続化**: タスクデータをブラウザに保存

## 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **UIライブラリ**: React 18
- **状態管理**: Zustand
- **スタイリング**: Tailwind CSS
- **日付処理**: date-fns
- **バリデーション**: Zod
- **テスト**: Vitest, Testing Library
- **ストーリーブック**: Storybook

## セットアップ

### 前提条件

- Node.js 18以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd task-freshness-todo

# 依存関係をインストール
npm install
```

## 使い方

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてアプリケーションを表示します。

### タスクの作成

1. フォームにタスクのタイトルを入力
2. 説明（オプション）を追加
3. 期限日を設定
4. 優先度を選択（低・中・高）
5. 「追加」ボタンをクリック

### タスクの管理

- **編集**: タスクをクリックして内容を編集
- **完了**: チェックボックスをクリックしてタスクを完了
- **削除**: 削除ボタンでタスクを削除
- **墓石の表示**: 期限切れタスク（墓石）をクリックして内容を表示

### その他のコマンド

```bash
# 本番ビルド
npm run build

# 本番サーバー起動
npm start

# テスト実行
npm test

# テスト（ウォッチモード）
npm run test:watch

# カバレッジ付きテスト
npm run test:coverage

# Storybook起動
npm run storybook

# パフォーマンス分析
npm run performance:analyze

# パフォーマンスベンチマーク
npm run performance:benchmark
```
